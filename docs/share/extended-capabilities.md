# Share 媒体生成与工具

> 权威实现规范。线协议见 Router 的 PROTOCOL.md §13.7。

## 管理入口

在 Server 的远程分享、Router 仪表盘或独立 Share 管理页打开“编辑用户授权与配额”，在用户额度下开启所需操作。新授权和 owner 自用默认全关。个人弹窗先更新页面草稿，外层保存才生效。没有可配置操作或待撤销项时隐藏字段，读取异常允许重试，已有失效授权仍可关闭。

基础模型交互包括模型支持的图片、文档、音频和视频理解输入，以及客户端执行的工具。公开免费 Share 只向已认证且没有有效个人授权的调用者提供基础交互。个人授权达到限额、过期或缺少调用资格时按原准入规则处理。市场用户的权限来自冻结合同，只能查看。新市场合同冻结 schema 3 的空操作集合。

Server 从已启用的 Share 入口、个人允许的协议、Driver 执行合同和供应商配置决定候选项。账号明确不支持的操作不可授予。缺少账号观察证据保持未知，预览不发付费探测。Grok 媒体和 Codex 生图仍需其供应商开关。供应商有实现的操作才会出现在个人编辑器中。

## 授权与保存

开启某项操作会批准该用户当时可用的全部入口。每个入口的指纹绑定运行时身份和绑定历史。新增入口、换绑或账号身份变化后，原来仍匹配的入口继续可用，变化的入口需要重新确认。普通价格更新不会要求重新授权。复制授权、新建授权和撤销后重建都从基础权限开始。

管理预览使用控制接口 `/_ctl/preview_share_capabilities` 或 Server Web 管理 invoke。传入 Share 的配置版本和目标邮箱读取 `displayVersion:3` 的候选项。提交前对操作差量和目标额度做统一复核。新增或重新确认要求入口读取完整。只撤销操作也可在部分绑定不可读取时保存。

`grantCapabilityEdits` 按规范化邮箱记录预期授权版本、选择的操作及显式重新确认的操作。缺少该邮箱表示保留，空列表表示撤销其全部媒体与工具权限。Server 在提交时重新核对 Share、目标用户、入口、额度、价目和风险条件。执行权限独立于金额条款，待生效额度激活时不会恢复已经撤销的权限。

未覆盖的 Token 消耗按用户和操作汇总，一次确认记录全部具体条件。签名预览有效期为 15 分钟。额度、权限、审计与回执同一 SQLite 事务保存。响应丢失时以同一个操作 ID 和相同载荷恢复已有结果，修改草稿后使用新 ID。历史回执不能恢复已经删除的 Share 或授权。

## 准入与计量

| 当前额度 | 执行规则 |
| --- | --- |
| Token | 扣真实模型 Token。图片张数、视频时长与工具次数不折算成 Token。 |
| 美元 | 使用 Server 已生效的 API 等值价目。实际模型、服务档位和必要资源维度都能定价时才发送请求，明确零价有效。 |
| 无限额 | 记录能取得的用量，继续执行 Share 的总 Token、并发和有效期限制。 |

Token 或无限额请求留下的美元估值可用于后续额度转换。缺价不阻断这类请求，也不会显示为已扣美元。单位转换、人工校准、当前周期已用量和在途风险沿用原有账本和回执。

操作识别读取协议控制字段和最终模型。OpenAI 图片工具的自动动作需要生成与编辑两项授权。Gemini 显式仅输出文本时，图片理解仍按基础交互处理。未知供应商执行操作在发网前拒绝。

能力检查与额度准入在上游生成前完成。HTTP、流式请求、WebSocket 每次生成和真实重试都按当前授权检查。续接按 Router、安装实例、Share、用户、协议及绑定恢复原工具上下文。已准入请求按原尝试的价目、身份和窗口结算。实际响应出现计划外资源时保留证据和待结算风险，隔离受影响的绑定和授权范围。

## 请求详情

管理者按 Share、请求和尝试查询计量。列表区分实际扣美元额度、仅估值、没有美元额度和历史扣额无法确认。明细可展开查看原生用量、预占、缺价原因和冻结价目版本。设置页读取可配置操作时不查询历史记录。

## 升级与恢复

先升级 Router 到 v14 reader，再升级 Server 权威 SQLite 到 schema 10。在副本上核对各用户保留、收窄和待确认的权限，比较消费窗口、人工校准、在途请求及回执。启用新流量前确认 Router 已收到 v14 描述和最新配置版本。

迁移仅保留能证明曾按具名用户与具体入口批准的权限。旧公开权限收敛为基础交互，市场继续使用原冻结条款。未来普通美元请求采用缺价拒绝。已有账本和尝试不重新计价。迁移前留存可恢复副本。有新消费或新回执后，用能读取新格式的版本修复服务并保留账本。
